# 墨阅 · Markdown 解析器

本地 Markdown 阅读与编辑工具：拖入 / 选择文件或文件夹即可解析渲染，支持脚注、数学公式（MathJax）、Mermaid 图表、代码高亮、缩进层级列表、表格、任务清单等，并内置编辑模式（实时渲染、双向同步滚动、可保存）。**零联网、零外部依赖**，所有解析、渲染与编辑都在本机完成。

## 编辑器：Monaco 内核

编辑区基于 [Monaco Editor](https://microsoft.github.io/monaco-editor/)（VS Code 同款内核），并打包为**离线内嵌版本**（编辑器内核、worker、样式全部本地化，无任何外部请求）：

- **缩进折行**：开启 `wordWrap` + `wrappingIndent: same`，长行自动换行时，续行与逻辑行行首缩进对齐，不再顶格
- 编辑区内选中文字可直接拖拽移动（移动而非复制，拖动时显示虚线落点预览）
- 外部文本可拖入编辑区，光标实时跟随、在落点插入
- 词法高亮与阅读区配色统一（标题 / 链接 / 列表等使用主题强调色），跟随亮 / 暗色主题切换

## 渲染：全部本地

- Markdown 解析（表格、任务清单、脚注、嵌套列表、引用块、代码块……）
- **换行按原文保留**：段落里的普通换行（软换行）渲染为可见换行，多行文本不再被压成一行；行尾两空格仍是硬换行
- **脚注双向跳转**：正文上标 → 脚注解释，脚注末尾的 `↩` → 跳回正文引用处（同一脚注被引用多次时，每个引用点各有自己的 `↩`）
- **列表按 CommonMark 分块**：相邻的有序 / 无序列表各自成块（有序项保留编号），不会因为中间一个空行就让整块列表被判定为 loose、每项套上一层 `<p>` 而突然拉大高度
- **标题锚点**：各级标题自动生成 GitHub 风格 `id`（中文保留、重名依次 `-1`/`-2`），正文里的 `[文字](#标题)` 可以跳转，跳过去会居中并高亮落点
- **隐藏内容遮罩**：`||内容||`（Discord 同款）渲染成灰条遮罩，点击或回车显示；支持嵌套强调、行内代码，`\|\|` 可转义，代码块与数学公式里的 `||` 不受影响
- **图片路径**：相对路径（`a.svg` / `./a.svg` / `../a.svg`）与根路径（`/a.svg`）都能正常加载——根路径按「相对本程序」解析，不再指到磁盘根；独占一段的小图标（如自带 `width="1em"` 的 SVG）有最小显示尺寸
- MathJax（SVG 输出）渲染行内 / 块级数学公式
- Mermaid 渲染图表
- 代码高亮（20+ 语言）

## 交互细节

- 亮 / 暗主题切换带颜色过渡动画（不在首屏播放；系统开启「减弱动态效果」时自动退化为瞬切）
- 拖入 / 选择新文件后立刻切换到新文件浏览（正在看别的文档时同样切换）
- 进出编辑模式保持阅读位置：切到编辑时编辑区与预览都停在你正在看的那一段，退出时回到原处（不再每次都弹回顶部）

## 两个版本

| 文件 | 说明 |
|---|---|
| `index.html` | 原版：需与 `lib/` 目录同放，便于日常维护与二次开发 |
| `墨阅解析.html` | **单文件版**：Monaco 内核、worker、MathJax、Mermaid、样式全部内联进一个 HTML |

两者功能完全一致，任选其一。

## 快速开始

1. **电脑**：下载并打开 release 里的 HTML 文件，用浏览器打开即可使用（Windows / macOS / Linux 均可）；
2. **手机（安卓）**：把 release 里的 HTML 文件传到手机，用文件管理器找到它并用浏览器打开（微信内置浏览器也可运行）；
3. **导入文档**：把 `.md` 文件拖进窗口（支持一次多份或整个文件夹），或在空状态点击按钮选择；
4. **编辑模式**：右上角「编辑」进入左编辑右预览——左侧改动实时渲染到右侧，两侧滚动联动，可保存回本地（系统对话框或下载）。
5. 在线版（GitHub Pages）：[墨阅解析](https://reinlink.github.io/Markdown-/) —— 部署的是同一套代码，本地文件始终离线可用。

## 项目结构

```
Markdown解析/
├── index.html                         ← 目录版主程序
├── lib/
│   ├── mermaid.min.js                 ← 图表库（本地）
│   ├── mathjax-tex-svg.js             ← 数学公式库（本地，SVG 输出无需字体）
│   └── monaco/
│       ├── editor.bundle.js           ← Monaco 编辑器离线包（含 worker，Blob 内联）
│       └── editor.bundle.css          ← 编辑器样式（字体 data URI 内联）
├── editor-build/                      ← Monaco 离线包构建工程（维护用）
├── InkMark.html                       ← 单文件离线版（构建产物，在 release 里）
├── 构建单文件版.js                     ← 单文件版构建脚本（Node.js）
└── 测试.md                            ← 功能覆盖测试样例
```
